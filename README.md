# 💗 LOVE MAP — интерактивная карта вашей истории

Это самостоятельный сайт без сервера и базы данных.

## Файлы

- `index.html` — основная страница.
- `style.css` — дизайн, анимации и адаптация под телефон.
- `script.js` — события и логика карты.
- `images/` — сюда складываются фотографии.

## Как добавить событие

Открой `script.js` и найди:

```js
const EVENTS = [
```

Добавь новый объект:

```js
{
  date: "20.12.2026",
  title: "Наша встреча",
  description: "Здесь будет текст воспоминания.",
  image: "images/20-12-2026.jpg"
}
```

Порядок объектов = порядок событий на линии.

## Как добавить фотографию

1. Положи фотографию в папку `images`.
2. Например: `images/meeting.jpg`
3. В событии укажи:

```js
image: "images/meeting.jpg"
```

Если фотографии нет:

```js
image: ""
```

## Как изменить название сайта

Вверху `script.js`:

```js
const SITE = {
  title: "Наша история",
  subtitle: "Каждая точка — воспоминание, которое мы не хотим забыть."
};
```

## Как запустить

Самый простой способ — открыть `index.html` в браузере.

Для обычной работы с телефонами/ПК лучше загрузить всю папку на хостинг, сохранив структуру:

```text
index.html
style.css
script.js
images/
```

Сайт не требует базы данных или PHP.

## Что уже есть

- интерактивная карта;
- плавный zoom;
- перемещение карты мышкой;
- pinch-to-zoom на телефоне;
- пунктирная любовная линия;
- точки событий;
- даты и названия;
- карточка события;
- фотография для каждого события;

- мягкие CSS-анимации;
- режим `prefers-reduced-motion`.

## Важный момент

Координаты событий на карте рассчитываются автоматически по их количеству.
Тебе не нужно вручную рисовать линию или расставлять точки.

Просто добавляй новые события в `EVENTS`.


## Таймер отношений

Дата начала сейчас установлена на:

**28 августа 2026 года**

Если когда-нибудь понадобится изменить её, в `script.js` найди:

```js
const RELATIONSHIP_START = new Date(2026, 7, 28, 0, 0, 0);
```

Обрати внимание: в JavaScript месяцы начинаются с нуля, поэтому `7` = август.

Таймер показывает:

- полные годы;
- полные месяцы после годов;
- дни;
- часы;
- минуты;
- секунды.

Он обновляется каждую секунду.
